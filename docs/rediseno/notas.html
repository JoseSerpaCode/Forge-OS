Arquitectura general

avavery · editada hace 5 minAPIQ4Guardado

Forge OS corre como un solo proceso de Astro en modo servidor, sobre un archivo de SQLite. No hay una capa de API aparte: los manejadores de src/pages/api son la API.

Cómo encaja todo

Cada consulta va filtrada por workspace_id. Ese filtro es la frontera entre espacios, así que se aplica en la capa de datos y no en la interfaz. Lo detalla Búsqueda de texto completo en páginas, que es el primer caso que lo cruza.

  • Astro en modo servidor con el adaptador de Node.
  • better-sqlite3 para lecturas síncronas en el mismo proceso.
  • Socket.IO para las notificaciones en tiempo real.

Copias de seguridad

La base está en modo WAL. Copiar el archivo da una copia incompleta, así que la copia nocturna pasa por .backup y comprueba el resultado:

sqlite3 forge.db ".backup /var/backups/forge-$(date +%F).db"
sqlite3 /var/backups/forge-$(date +%F).db "PRAGMA integrity_check;"
